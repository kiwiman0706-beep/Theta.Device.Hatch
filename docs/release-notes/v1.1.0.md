### 主な機能
- 機器台帳（名前・管理番号・分類・メーカー・型番・製造番号・設置場所・IP・MAC・価格・購入日・管理画面URL・ID/PW・メモ）
- 1台に複数写真（本体／銘板・MAC／設置風景／その他）、端末内 OCR（ML Kit 日本語）で IP・MAC 等の候補抽出
- Gemini による写真認識（任意。API キーはアプリ内で入力し端末内で暗号化保存。APK には含まれません）
- SR5900P 向け QR（管理画面URL）付き管理ラベル：項目チェック選択・プレビュー・PNG 保存・印刷
- AES-GCM 暗号化保存、端末ロック認証、パスワード付き `.eqbk` バックアップ／追加式復元
