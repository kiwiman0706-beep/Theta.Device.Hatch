# コンセプトとユーザー要望

## コンセプト

PCや電子機器のある場所で、本体・銘板・MAC表示・設置風景をスマートフォンで撮影し、そのまま機器台帳を作る。メーカーや型番の転記をOCRとGemini画像認識で補助する。管理画面のURL、ログイン情報、設置場所などを写真と一緒に保管し、SR5900Pから必要項目だけを載せたQR付き管理ラベルを印刷して機器に貼る。

管理ラベルのQRのリンク先は、登録した**機器の管理画面URL**。アプリの台帳一覧をWeb公開する仕組みとは別。

## ユーザーの明示要望

| 要望 | 現在の対応 |
|---|---|
| Androidアプリ、APKで受け取りたい | ネイティブJava製、Android 11以降、1.1.0 APK |
| PC・電子機器をカメラで撮影したい | カメラ経由の写真追加 |
| MACアドレスの表示も撮影したい | 銘板・MAC写真のOCR、Gemini補助 |
| 設置風景も撮影したい | 写真の分類「設置風景」 |
| 1製品に写真を複数撮りたい | 1台に複数写真、画像ファイルの複数選択 |
| IP、MAC、メーカー、型番、設置場所、価格をDB化 | 各入力欄と暗号化SQLiteレコード |
| 管理画面アドレス、ID/PW、メモを管理 | 対応 |
| 写真も含めてDBとして管理 | レコードが写真IDを参照し、写真本体は暗号化ファイルで保存 |
| SR5900Pから管理ラベルを出力 | 公式SDKによるネットワーク直接印刷のコードを実装。実機印字未検証 |
| ラベルに管理画面ページのQRを載せたい | URLのみをQR化 |
| 出力項目をチェックで選びたい | チェック選択、プレビュー、PNG保存 |
| Google画像検索やAI認識で型番・メーカー入力を補助 | Gemini画像認識を実装。Google画像検索・Web検索は未実装 |
| APIキーをコードに入れずアプリ内入力へ変更 | 最終仕様として実装。設定は暗号化、バックアップからも除外 |
| 提供キーをアプリのテストに使ってよい | 過去の実APIテストで使用。値はこのZIPへ持ち込まない |
| 別スレッドへ引き継ぐため全資料をZIP化 | 本ZIP |

## アシスタントが補完した設計（ユーザーの直接指定とは区別）

- 端末内保存。サーバーやユーザー登録なし。クラウド同期・複数端末同期なし。
- 端末画面ロック認証、スクリーンショット抑止、60秒以上バックグラウンド後の再認証。
- SQLiteのJSONレコードと写真をAES-GCM暗号化。鍵はAndroid Keystore。
- パスワード付き .eqbk バックアップと追加式復元。
- 機器の編集・削除・検索、下書き保持、MAC重複時の確認。
- 管理番号、分類、製造番号、購入日を追加。
- 写真分類は「本体」「銘板・MAC」「設置風景」「その他」。
- ID/PWはラベルの初期選択から外し、選択時は印刷確認で知らせる。
- テープ幅は12/18/24/36mm、1回1枚。実際の装着幅との不一致は停止。
- Geminiは写真1〜4枚をユーザーが選び、候補と確度・根拠を確認して反映。項目チェックは初期状態で全てオフ。

## APIキーの最終決定

最初にユーザーは個人用なのでキーの組み込みを許可したが、その後「コードには入れずアプリ内で入力」に変更した。この後者が有効。APK、ソース、会話記録、サンプル設定へ実キーを埋め戻さない。

## このスレッドで依頼されていない機能

PC/Mac版、Web管理画面、Google Drive同期、GitHubへの公開、他機種向け印刷、音声ラベル入力は本アプリの確定要望ではない。別アプリの会話と混ぜない。Google画像検索は検討質問があったが、現在の実装はGeminiのみ。
